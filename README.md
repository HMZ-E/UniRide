# UniRide

## Overview
UniRide is a dedicated mobile transit application developed exclusively for iOS, tailored to streamline the daily commute for students navigating the transit network in Settat. The application provides accessible insights into transit schedules and routes, ensuring a more reliable and predictable travel experience across the city.

## Key Features
* Route Navigation: Clear visualization of student-specific transit routes across the local area.
* Schedule Tracking: Access to transit timetables to assist with accurate journey planning.
* Student-Centric Interface: A highly accessible and intuitive layout designed for quick use while commuting.
* Location Services: Integration with native iOS location frameworks for accurate positioning and mapping.

## Technical Stack
* Platform: iOS
* Framework: SwiftUI
* IDE: Xcode
* Language: Swift

## Installation and Setup
1. Clone the repository to your local machine.
2. Open the `UniRide.xcodeproj` file in Xcode.
3. Ensure your Xcode environment is configured with an active iOS simulator or a connected physical iOS device.
4. Build and run the application.
